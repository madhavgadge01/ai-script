1.1 CPU Components and Internal Register Organization

The CPU serves as the primary computational engine of the computer system. It coordinates operations through the Control Unit and carries out mathematical and boolean transformations via the Arithmetic and Logic Unit, supported by dedicated high-speed internal registers.

  • Arithmetic and Logic Unit (ALU): Executes fundamental arithmetic operations (addition, subtraction, multiplication, division) and boolean logic operations (AND, OR, NOT, bit-shift comparisons).
  • Control Unit (CU): Acts as the operational supervisor, generating clock-synchronized timing and control signals to govern instruction fetching, register transfers, and bus interactions.
  • Program Counter (PC): Holds the memory address of the subsequent instruction to be fetched.
  • Instruction Register (IR): Holds the operational code (opcode) of the currently executing instruction.
  • Memory Address Register (MAR): Holds the physical memory address referenced during read and write cycles.
  • Memory Buffer Register (MBR): Holds the actual data word read from or written to main memory.
  • Accumulator (AC): Preserves intermediate computational operands and results.
CPU Execution Time CPU Time = Instruction Count * Cycles Per Instruction (CPI) * Clock Cycle Time
