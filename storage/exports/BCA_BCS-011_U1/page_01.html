1.0 Conceptual Definition and Functional Units

A computer is defined as a high-speed electronic calculating machine that accepts digitized input information, processes it according to an internal sequence of stored instructions, and produces the resulting output. The instruction sequence is designated as a computer program, while internal retention circuitry is designated as computer memory.

  • Input Unit: Transduces physical external signals into standardized digital binary representations.
  • Central Processing Unit (CPU): Executes stored program instructions via the Arithmetic Logic Unit and Control Unit.
  • Memory Unit: Retains program instructions and active runtime data operands.
  • Output Unit: Delivers computed results in human-readable or machine-readable format.
Computer System: A high-speed electronic calculating machine that accepts digitized input information, processes it according to a list of internally stored instructions, and produces the resulting output information.
Von Neumann Architecture: The foundational architectural model wherein program instructions and operational data reside simultaneously within a unified physical memory address space, sequentially accessed, decoded, and executed by the Central Processing Unit.
