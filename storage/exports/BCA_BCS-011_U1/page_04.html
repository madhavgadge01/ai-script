1.3 Input-Output Subsystems and Data Transfer Modes

Input/Output modules mediate between the internal processor/memory buses and peripheral equipment, ensuring controlled data synchronization across diverse device speeds via distinct operational transfer mechanisms.

  • Programmed I/O: CPU engages in busy-waiting loops, continuously polling device status registers until ready.
  • Interrupt-Driven I/O: CPU initiates transfer, executes other tasks, and responds only when an asynchronous interrupt signal is issued by the peripheral.
  • Direct Memory Access (DMA): Dedicated hardware controller manages high-throughput block data movement directly to/from main memory without continuous CPU intervention.
[IMP] [IMP] Comparison of I/O Transfer Mechanisms: Programmed I/O wastes extensive processor cycles through continuous status flag polling (busy waiting). Interrupt-Driven I/O frees the CPU to execute concurrent workloads until an I/O device asserts a hardware interrupt pin. Direct Memory Access (DMA) completely bypasses the CPU for bulk block transfers between memory and I/O devices via a dedicated DMA controller.
