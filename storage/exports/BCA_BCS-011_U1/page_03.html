1.2 Memory Hierarchy Design and Principle of Locality

Modern computer architectures implement a hierarchical memory model to balance speed, storage capacity, and cost per bit. High-speed, high-cost storage technologies are placed nearest to the processor, backed by larger, slower, and more economical tiers.

  • Processor Registers: Access latency ~0.5 - 1 ns, capacity < 2 KB, highest manufacturing cost per bit.
  • Primary Cache (L1, L2, L3): SRAM placed adjacent to the processor core, operating at access latencies of ~1 - 10 ns.
  • Main Memory (RAM): Dynamic RAM (DRAM) offering moderate access latencies of ~50 - 100 ns with gigabyte capacities.
  • Secondary Storage: Magnetic hard disk drives (HDD) and solid-state drives (SSD) offering non-volatile retention with millisecond and microsecond latencies.
Average Memory Access Time (AMAT) AMAT = Hit Time + (Miss Rate * Miss Penalty)
Principle of Locality: The empirical operational property governing memory access patterns, divided into: (1) Temporal Locality: If a memory location is referenced once, it will likely be referenced again soon (e.g., loop control variables); (2) Spatial Locality: If a location is referenced, adjacent memory addresses will likely be referenced in the near future (e.g., consecutive array traversal).
Locality Application Examples: Loop index variables exemplify Temporal Locality by being iteratively read and updated in rapid succession. Linear array processing exemplifies Spatial Locality by referencing contiguous memory cells sequentially.
